## 🛡️ Kalite Değerlendirme Kriterleri

Her repo GitCurator'a giremez. Bot aşağıdaki 7 katmanlı değerlendirme filtresini uygular:

1. **Resmi Açık Kaynak Lisansı:** Yalnızca OSI onaylı (MIT, Apache-2.0, GPL, BSD vb.) lisansı olan repolar kabul edilir.
2. **Özgünlük (No Forks):** Fork edilmiş kopyalar doğrudan elenir.
3. **Anti-Spam / Anti-Tutorial:** Ödev, kurs, hile sayfası veya "awesome-list" listeleri elenir; yalnızca çalışan gerçek yazılımlar seçilir.
4. **Tazelik & Momentum:** Son 30 günde açılmış veya son 72 saatte aktif commit almış olmalıdır.
5. **Zengin Açıklama:** Açıklaması boş veya 20 karakterden kısa olan özensiz repolar elenir.
6. **Dil Çeşitliliği:** Rust, Go, TypeScript, Python, Zig vb. diller arasında dengeli dağılım sağlanır.
7. **Kategorizasyon:** 15 repo Günün Vitrini, AI, DevTools, Web ve Gizli Cevherler olarak 5 gruba ayrılır.
