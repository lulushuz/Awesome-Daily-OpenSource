## Evaluation Criteria

Every candidate repo must pass 7 automated quality filters:

1. **OSI-Approved License:** Must have an official open-source license (MIT, Apache-2.0, GPL, BSD, etc.).
2. **Original Software (No Forks):** Duplicates, mirrors, and forks are excluded.
3. **Anti-Spam & Anti-Tutorial:** Homework, cheat sheets, interview prep, and static awesome-lists are filtered out.
4. **Fresh Momentum:** Created in the last 30 days or pushed in the last 72 hours.
5. **Quality Description:** Must include a meaningful description (>= 20 characters).
6. **Stack Diversity:** Balanced spread across Rust, Go, TypeScript, Python, Zig, and C.
7. **Balanced Scoring:** Categorized into Top Picks, AI/ML, DevTools, Web, and Hidden Gems (< 250 stars).
